Agents look up the evidence for each story, including release tags that show merged work has shipped, and can claim stories when several agents work at once. Internal viewers copy an agent brief for a story or release from its panel, or open it in Claude or ChatGPT.

Release notes

The second half of the native CLI plan. It comes before the scheduled audit (ESM-109), which uses the evidence from ESM-105.

Agent briefs (ESM-123, ESM-124 and ESM-125) come early, to test the brief format on real stories before the command-line brief and local launch in 0.8.1.

Plans: docs/plans/native-cli.md and docs/plans/agent-briefs.md

Expected impact

  • Agents starting the same story at the same timeDraft

    Expected
    None, for teams that use claims
    Solves
    Duplicate work when several agents pick from one map

  • Stories left in merged after their release goes outDraft

    Expected
    Suggested as shipped by story-map evidence, for products that tag their releases
    Solves
    The map showing released work as not yet available

  • Time to hand a story or release to a coding agentDraft

    Expected
    One copy from its panel, instead of writing the prompt by hand
    Solves
    Agents starting work without the plan, the work already built nearby or the repository's rules
