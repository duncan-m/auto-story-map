Merged

story-map tokens counts the model tokens Claude Code used on a story from its session logs, by branch or session, estimates their cost at API list prices, and prints a Tokens used section for the pull request that finishes it. story-map edit --tokens and --estimated-cost record both on the story, shown in the internal story panel.

Engineering

Reads the logs on the machine that runs it, with no network calls. Other agents record a count and cost by hand. Internal only. The cost is an estimate at dated, built-in list prices that --prices can replace, not what was billed. No dashboards or comparisons between agents, which the delivery metrics plan leaves out.
