Release

0.7.2: CLI to read, edit and preview the map

Agents read the map, validate it and propose edits with story-map commands that print JSON, and anyone can preview their own map locally before adding the board to their product.

Release notes

The first half of the native CLI plan, moved ahead of personas so agents can tag the existing stories with story-map edit instead of editing the YAML by hand. Evidence and claims follow in 0.7.5.
